🚚 Otimizador de Rotas - Entregador

Como configurar a ordem das ruas:

  • Digite as ruas na ordem que você normalmente percorre
  • Separe cada rua por vírgula
  • Os dados são salvos automaticamente no seu celular
  • Exemplo: Rua A, Rua B, Rua C, Avenida Principal

🔄 Ruas Salvas Atualmente:

Como adicionar entregas:

  • Selecione uma rua da sua lista pré-salvada
  • Digite os números das casas para entregar
  • Clique em "Adicionar Número" para cada endereço
  • Repita para todas as ruas com entregas
⚠️ Você precisa configurar as ruas primeiro na aba "Configurar Ruas"
